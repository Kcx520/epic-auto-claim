# Epic 每周免费游戏 · 自动领取工具

一个完全跑在你自己电脑上的「喜加一」自动领取工具。
配置一次之后，每周 Epic 换免费游戏时它会自动帮你领进库，并给你发邮件。

**不需要 Docker、不需要关掉两步验证、不需要申请任何 AI 接口的 Key。**

---

## 它是怎么做到「不关 2FA」的

市面上大多数方案要么让你关掉两步验证，要么用 AI 去破解 hCaptcha 验证码。

这个工具换了个思路：**用你自己的手登录一次**，然后把登录状态存进一个专属的浏览器配置目录里，之后每次自动领取都复用这个状态。

好处很直接：

- 验证码、两步验证、邮箱验证码，全部由你按正常流程操作，工具不碰你的密码
- 不需要关 2FA，账号安全等级不下降
- 不需要任何第三方 AI 服务，不需要额外的 Key 和费用

## 快速上手（5 步）

按顺序双击这些文件即可，**每个文件打开后都有中文说明**。

### 1. 双击 `1-安装.bat`

检查并安装 Node.js（会优先用 winget，失败就自动从 nodejs.org 下载官方安装包），
然后安装两个依赖：`playwright-core`（驱动浏览器）和 `nodemailer`（发邮件）。

> 不会下载额外的 Chromium，直接用你系统里的 Edge，所以很快。

### 2. 双击 `2-登录Epic.bat`

弹出一个**独立的**浏览器窗口（和你日常用的浏览器互不影响，不会串号）。

在这个窗口里登录你的 Epic 账号，登录完成后**直接把窗口关掉**，程序会自动保存状态。

### 3. 双击 `7-体检.bat`

检查能不能在本周免费游戏的商品页上找到「获取」按钮。
**只查找、不点击、不改动账号**，用来确认链路正常。

### 4. 双击 `3-立即领取.bat`

立刻手动领一次。会弹出一个 Edge 窗口（正常现象，别关它），
全程自动：打开商品页 → 点「获取」→ 确认 → 完成。已经在库里的会自动跳过。

### 5. 双击 `4-安装定时任务.bat`

在 Windows 任务计划程序里创建一个名为 `EpicAutoClaim` 的任务，**每天 23:30 自动领取**。
浏览器窗口会被移到屏幕外，不会打扰你用电脑。

到这一步就完事了，之后不用再管。

### 可选：配置邮件通知

用记事本打开 `config.json`，把 `email` 部分改成你自己的邮箱，然后双击 `6-测试邮件.bat`。
QQ 邮箱的授权码获取方法写在该文件的中文提示里。

## 配置项（config.json）

```jsonc
{
  "locale": "zh-CN",          // 商城语言
  "country": "CN",             // 商城区域

  "browser": {
    "channel": "msedge",       // msedge / chrome
    "headless": false,         // 【必须 false】见下方说明
    "hideWindow": true,        // 把窗口移到屏幕外，不打扰你
    "slowMo": 0
  },

  "autoLoginWhenExpired": true, // 登录过期时自动弹窗让你重新登录
  "loginWaitMinutes": 10,       // 等你手动登录的最长时间
  "stepDelayMs": 1500,          // 每步之间的停顿
  "keepOpenSeconds": 0,         // 领完后浏览器多停几秒（0=立即关闭）

  "email": {
    "enabled": false,          // 改成 true 开启邮件通知
    "smtpHost": "smtp.qq.com",
    "smtpPort": 465,
    "secure": true,
    "user": "你的邮箱@qq.com",
    "pass": "邮箱授权码（不是登录密码）",
    "from": "",                // 留空则用 user
    "to": "收件邮箱@qq.com",
    "always": false            // false=只在有新领取或出错时发信
  }
}
```

### 为什么 `headless` 必须是 `false`

这是**真机实测**出来的结论，不是猜的：

| 模式 | 结果 |
| --- | --- |
| `headless: true`（无界面） | ❌ Epic 的 Cloudflare 风控会**永久**把你卡在「请完成安全检查」页面，等 45 秒也不放行 |
| `headless: false`（有界面） | ✅ 3 秒放行，页面正常加载 |

所以工具默认用「有界面 + 窗口移到屏幕外」的方式运行，既不会被风控拦，也不影响你用电脑。
如果你手动把 `headless` 改成 `true`，脚本会打印警告，而且大概率领不到。

## 常见问题

| 现象 | 原因和处理办法 |
| --- | --- |
| 提示「被 Epic 的安全检查拦住」 | 双击 `3-立即领取.bat`（有界面模式）跑一次，在弹出的窗口里手动通过验证，之后配置目录会记住这个通行证 |
| 提示「没找到『获取』按钮」 | Epic 改了页面结构。把 `screenshots\` 里最新的截图发出来即可定位修复 |
| 提示需要重新登录 | 登录状态过期了，双击 `2-登录Epic.bat` 重新登录一次 |
| 浏览器窗口一闪而过 / 报「正被另一个程序占用」 | 上一次运行还没结束。把弹出的浏览器窗口全部关掉，等几秒再试 |
| 定时任务跑了但没领到 | 看 `logs\` 里当天的日志；定时任务自身的启动记录在 `logs\task.log` |
| 邮件发不出去 | QQ/163 必须用**授权码**而不是登录密码；Outlook 用 587 端口且 `secure` 要改成 `false` |
| 想改自动领取时间 | 记事本打开 `tools\install-task.ps1`，改开头的 `-Time '23:30'`，再双击一次 `4-安装定时任务.bat` |

## 关于「为什么每天跑」

Epic 的免费游戏在**每周四晚上**换新（北京时间约 23:00–24:00），每个游戏免费一整周。

每天跑一次能保证不漏掉任何一次，而且重复运行是**安全**的：
脚本会先检查该游戏是否已经在你的库里，在的话直接跳过，不会产生多余订单。

定时任务还开了 `StartWhenAvailable`，如果到点时电脑没开机，开机后会自动补跑。

## 已知限制与风险

- **页面结构依赖**：本工具通过识别「获取」按钮来领取。Epic 若大改商城前端，需要更新脚本。
  出问题时用 `7-体检.bat` 定位，`screenshots\` 里会留下证据。
- **登录状态会过期**：过期时工具会自动弹出浏览器让你重新登录（默认最多等 10 分钟），
  并在邮件里提醒你。如果那时你不在电脑前，这次领取会失败，但下次仍会重试。
- **账号风险**：自动化操作 Epic 商城可能违反其服务条款，请自行评估。
  建议先在小号上跑通再用于主号。
- **登录状态即钥匙**：`browser-profile\` 文件夹等同于你的账号登录态，
  不要分享、不要上传到网盘或代码仓库。
- **本工具不接触你的密码**：登录完全由你在浏览器里手动完成，脚本不读取、不存储你的账密。

## 卸载

1. 双击 `5-卸载定时任务.bat` 取消自动领取
2. 直接删除整个 `EpicAutoClaim` 文件夹

Node.js 是系统级安装的，如需卸载请到「设置 → 应用」里移除 `Node.js`。
